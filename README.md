# SkyResources

SkyResources is an English Hypixel SkyBlock resource hub built with Next.js. It collects practical guides, quick links, and topic-specific pages in one place so players can jump to the right information fast.

## What you will find

- **Early Game** — foundations, priorities, and beginner-friendly progression
- **Mid Game** — efficient upgrades, scaling, and better resource planning
- **End Game** — high-end optimization, meta routes, and advanced goals
- **Money** — farming, mining, flipping, and other profit methods
- **Mining** — locations, gear, and progression for efficient mining
- **Garden** — crop progression, tools, and farming profit checks
- **Dungeons** — class progression, gear paths, and dungeon prep
- **Mayors & Events** — event tracking, planning, and preparation
- **News** — patch notes and important updates
- **Shards & Hunting** — drops, routes, and tracking tools
- **Mods** — useful quality-of-life and performance mods
- **Tricks** — small mechanics and habits that save time

## Site structure

- The home page acts as a topic hub with cards for every guide.
- The sidebar navigation is shared across the site and links every guide together.
- Guide pages are meant to reference related topics, so players can move between connected subjects like Mining, Money, and progression guides without leaving the site flow.
