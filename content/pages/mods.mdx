## Why Use Mods?

SkyBlock has extremely deep systems that are nearly impossible to track manually. Mods and external tools help you:
- Track **prices** and find profitable trades
- See **auction/bazaar data** in-game
- Get **dungeon guidance** (secrets, puzzle solutions)
- Automate stat tracking and alerts
- Identify profit opportunities

<Warning title="Only use trusted mods">
Only install mods from official sources (GitHub, known mod developers). Third-party launchers or "mod packs" from unverified sources may contain malware or stolen code. Stick to the community-trusted list below.
</Warning>

---

## Minecraft Version Note

Most SkyBlock mods are built for **Minecraft 1.8.9** (for FPS performance) or **1.21+** (newer mods). Check which version a mod requires before installing.

- **1.8.9**: Most popular for PvP-style FPS. SkyHanni, NEU work here.
- **1.21+**: New mods increasingly target this. Better graphics support.

## Essential Mods

### SkyHanni

**The most important SkyBlock mod.** SkyHanni adds hundreds of QoL features:
- Dungeon secrets tracking (shows where secrets are in each room)
- Puzzle solutions for Dungeon puzzles
- Profit display for slayers, farming, fishing
- Notification alerts (slayer boss spawned, event starting)
- Farming overlay (FF display, crop counter)
- Pet auto-swap based on tool
- Trackers for virtually everything

> **Download**: [GitHub — SkyHanni](https://github.com/hannibal002/SkyHanni)

---

### NotEnoughUpdates (NEU)

NEU is a comprehensive item database and in-game tool:
- Search any item by name and see recipes, prices, collection thresholds
- Estimated item value overlay
- Dungeon profit calculator
- Recipe viewer for all items
- Storage and backpack organization

> **Download**: [GitHub — NotEnoughUpdates](https://github.com/NotEnoughUpdates/NotEnoughUpdates)

---

### Firmament (1.21+)

Modern rewrite of NEU for 1.21+:
- Same item lookup and recipe viewer features
- Built for newer Minecraft versions
- Actively maintained

> **Download**: [GitHub — Firmament](https://github.com/nea89o/Firmament)

## Installing Mods

### Using a Mod Launcher (Recommended)

1. Download **Prism Launcher** (free, open-source) or **Forge** for 1.8.9.
2. Create a new instance with your target Minecraft version.
3. Add downloaded `.jar` mod files to the `mods/` folder of your instance.
4. Launch and connect to `mc.hypixel.net`.

### Manual Installation

1. Find your Minecraft folder (`.minecraft`).
2. Create a `mods` folder inside if it doesn't exist.
3. Drop mod `.jar` files in.
4. Make sure Forge/Fabric is installed for your version.

<Tip title="Keep mods updated">
SkyBlock updates can break mod features. Check the mod's GitHub page or Discord when a new patch drops to see if an update is needed.
</Tip>
