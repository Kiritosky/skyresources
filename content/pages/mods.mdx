## Why Use Mods?

SkyBlock has extremely deep systems that are nearly impossible to track manually. Mods and external tools help you:
- Track **prices** and find profitable trades in real-time
- See **auction/bazaar data** without leaving the game
- Get **dungeon guidance** (secrets, puzzle solutions)
- Automate stat tracking, pet swapping, and alerts
- Identify profit opportunities before others

<Warning title="Only use trusted mods">
Only install mods from official sources (GitHub, known mod developers). Third-party "mod packs" from unverified sources may contain malware. Stick to the community-trusted list below.
</Warning>

## Essential Mods

<Tabs>
<Tab label="SkyHanni">

**The most important SkyBlock mod.**

SkyHanni adds hundreds of quality-of-life features:

- Dungeon secrets tracking (shows secret locations room-by-room)
- Puzzle solutions for all dungeon puzzles
- Profit display for slayers, farming, fishing
- Notification alerts (boss spawned, event starting)
- Farming overlay (FF display, crop counter, speed)
- Pet auto-swap based on equipped tool
- Trackers for virtually everything

**Version**: 1.8.9  
**Download**: [github.com/hannibal002/SkyHanni](https://github.com/hannibal002/SkyHanni)

</Tab>
<Tab label="NEU">

**NotEnoughUpdates — comprehensive item database.**

- Search any item by name: see recipes, prices, collection thresholds
- Estimated item value overlay in your inventory
- Dungeon profit calculator
- Recipe viewer for all craftable items
- Storage and backpack organization

**Version**: 1.8.9  
**Download**: [github.com/NotEnoughUpdates/NotEnoughUpdates](https://github.com/NotEnoughUpdates/NotEnoughUpdates)

</Tab>
<Tab label="Firmament">

**Modern NEU replacement for Minecraft 1.21+.**

Same core features as NEU — item lookup, recipe viewer, price overlay — but built for newer Minecraft versions and actively maintained.

**Version**: 1.21+  
**Download**: [github.com/nea89o/Firmament](https://github.com/nea89o/Firmament)

</Tab>
</Tabs>

## FAQ

<Details title="Is using mods against the Hypixel rules?">
Client-side informational mods (SkyHanni, NEU, Firmament) are generally allowed on Hypixel. They display information but don't automate gameplay in ways that violate the rules. Always check the current Hypixel mod policy for the latest official stance before installing anything new.
</Details>

<Details title="Which version should I play on?">
**1.8.9** has the most mod support and better FPS for most systems. If you want better graphics, shaders, or prefer newer Minecraft features, use **1.21+** with Firmament instead of NEU.
</Details>
