## Overview

Write your introduction here. Keep it short — 2–4 sentences. Tell the reader what this page covers and what they'll be able to do after reading it.

You can use **bold** for key terms, *italic* for emphasis, ~~strikethrough~~ for deprecated info, and `inline code` for item names, commands, or values like `/warp hub`.

## Callout Boxes

The `title` prop is optional on all callouts — the icon still shows without it.

<Tip title="Pro Tip">
Use `<Tip>` for strategies, shortcuts, and "did you know" moments. Green border, lightbulb icon.
</Tip>

<Info title="Good to Know">
Use `<Info>` for neutral context that adds value but isn't a warning. Blue border, info icon.
</Info>

<Warning title="Watch Out">
Use `<Warning>` for things players commonly get wrong or should approach carefully. Gold border, warning icon.
</Warning>

<Danger title="Don't Do This">
Use `<Danger>` for mistakes that cost a lot of coins or progression. Red border, alert icon. Reserve for genuinely serious stuff.
</Danger>

## Tables

Write standard markdown tables — styling is applied automatically.

| Column A | Column B | Column C |
|----------|----------|----------|
| Row 1    | Value    | Notes    |
| Row 2    | Value    | Notes    |
| Row 3    | Value    | Notes    |

### Column Alignment

Control alignment with colons in the separator row:

| Left aligned | Centered | Right aligned |
|:-------------|:--------:|--------------:|
| text         | text     | 100           |
| text         | text     | 2,500         |
| text         | text     | 10,000,000    |

### Table Tips
- Keep column headers short (they're bold and uppercase automatically)
- Use `—` for empty cells rather than leaving them blank
- Sort rows logically (ascending by level/cost, or most important first)
- Numbers: use commas — write `1,000,000` not `1000000`

## Lists

### Unordered (bullet points)
Use for features, options, or things with no specific order:
- First item
- Second item
- Third item with a sub-list:
  - Nested item (indent 2 spaces)
  - Another nested item
- Back to top level

### Ordered (numbered steps)
Use when sequence matters — tutorial steps, upgrade paths:
1. First do this
2. Then do this
3. Finally do this

## Section Heading (h2)

Use `##` for main page sections. These divide the page into major topics.

### Subsection (h3)

Use `###` for a topic within a section. Good for breaking up long sections.

#### Minor label (h4)

Use `####` sparingly — it renders as small uppercase text, good for labels like "Early Game" or "Budget Option".

## Text Formatting

| Syntax | Result | When to Use |
|--------|--------|-------------|
| `**text**` | **text** | Key terms, item names, important values |
| `*text*` | *text* | Mild emphasis, flavor |
| `~~text~~` | ~~text~~ | Deprecated items, outdated info |
| `` `text` `` | `text` | Commands, item IDs, exact values |

## Progression Steps

Simple version — just strings:

<Steps title="Recommended order" steps={[
  "Do this first",
  "Then do this",
  "Then this",
  "Finally this",
]} />

With status markers — shows progress visually:

<Steps title="Your roadmap" steps={[
  { label: "Step you already finished", status: "done" },
  { label: "What you should do right now", description: "This is the most important step", status: "current" },
  { label: "Next step after that", status: "upcoming" },
  { label: "Long-term goal", description: "Don't worry about this yet", status: "upcoming" },
]} />

## Stat Cards

Single stat:

<Stat label="Coins/hr" value="15M" trend="up" note="With budget setup" />

Multiple stats side by side:

<StatRow>
  <Stat label="Coins/hr" value="15M" trend="up" />
  <Stat label="Setup Cost" value="50M" />
  <Stat label="Skill Req." value="30+" />
  <Stat label="HotM Req." value="7+" note="Minimum" />
</StatRow>

`trend` accepts `"up"` (green), `"down"` (red), or `"neutral"` (dash). Leave it out if not relevant.
